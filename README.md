# GOST_R_7.0.100-2018
Стиль оформляет список литературы по ГОСТ Р 7.0.100-2018. Сначала идут русскоязычные источники, затем иностранные, внутри каждой группы – по алфавиту. Файл стиля:GOST_R-7_0_100-2018_RU_First.csl, в Mendeley он называется «ГОСТ Р 7.0.100-2018 (алфавит, сначала русскоязычные; Notes = 0/1)»
