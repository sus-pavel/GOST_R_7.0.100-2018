# Стиль ГОСТ Р 7.0.100-2018 для Mendeley

## О стиле
Стиль оформляет список литературы по ГОСТ Р 7.0.100-2018.

**Ссылки в тексте** — номер в квадратных скобках: \[1\], \[1, с. 25\], \[1–3\], \[2, 5\]. Номера присваиваются по порядку в списке, а не по порядку упоминания.

**Порядок в списке:**
1. Метка в поле заметок (проставляется вручную): сначала 0 (русские), потом 1 (иностранные). Записи без метки уходят в самый конец списка — так легко заметить, что метку забыли.
2. Фамилия первого автора. Если автора нет (сайты, нормативные акты, патенты), запись ставится по первому слову заглавия в общий алфавит.
3. Работы автора без соавторов идут раньше его работ с соавторами. Соавторские — по алфавиту второго, третьего и следующих авторов.
4. Работы одного автора — по алфавиту заглавий, затем по году.

**Оформление записи:**

- Заголовок — первый автор в форме «Фамилия, И. О.».
- После заглавия и косой черты повторяются авторы: до четырёх включительно — все, при пяти и более — первые три и \[и др.\].
- Области описания разделяются точкой и тире: «. – ».
- Сведения о журнале: «Т. 40, № 3. – С. 307–332», дефис в страницах заменяется на тире.
- У статей в конце ставится DOI, у сайтов — «URL: … (дата обращения: ДД.ММ.ГГГГ)».

## Установка

**Mendeley Desktop (старая версия программы):**

1. Откройте View → Citation Style → More Styles.
2. Перетащите файл `.csl` в открывшееся окно. Другой вариант — вкладка Get More Styles, поле Download Style, туда вставляется ссылка на файл.
3. Выберите стиль в списке View → Citation Style. В Word плагин Mendeley подхватит его через выбор стиля на панели.

**Mendeley Reference Manager + Mendeley Cite (новая версия, плагин в Word):**

1. В Word откройте вкладку References → Mendeley Cite.
2. Перейдите в Citation Settings → Change citation style.
3. Пролистайте вниз и нажмите Add a custom style.
4. Вставьте ссылку на файл стиля и нажмите Update citation style.

## Разметка источников: 0 и 1

Каждой записи в библиотеке нужна метка языка в поле заметок: **0** — русскоязычный источник, **1** — иностранный. Стиль не определяет язык сам, он сортирует только по этой метке.

1. Выберите запись в Mendeley и откройте вкладку Notes (в новой версии — General notes в панели записи).
2. Впишите одну цифру: 0 или 1. Больше ничего в поле не пишите — ни пробелов перед цифрой, ни комментариев.
3. Повторите для всех записей, которые входят в список.

Если у записи метки нет, она окажется в самом конце списка после иностранных источников. Пролистайте готовый список: всё, что стоит после последнего иностранного источника, надо разметить.

## Как заполнять поля

Стиль собирает запись из полей Mendeley, поэтому результат зависит от того, какой выбран тип записи и что в нём заполнено.

| Тип записи в Mendeley | Что заполнить | Особенности |
| --- | --- | --- |
| Journal Article | Авторы, заглавие, журнал, год, том, номер, страницы, DOI | URL не печатается, только DOI |
| Book | Авторы, заглавие, город, издательство, год, число страниц, издание | Издание «2» превращается в «2-е изд.» |
| Book Section | Авторы, заглавие главы, название книги, редакторы, город, издательство, год, страницы | Редакторы — после названия книги: «/ редакторы …» |
| Conference Proceedings | Авторы, заглавие доклада, название сборника, город, издательство, год, страницы | Сведения о конференции (номер, место, даты) пишите в название сборника после « : » |
| Thesis | Автор, заглавие, Type (например, «дис. … канд. техн. наук : 2.4.2»), университет, город, год, число страниц | Университет печатается после автора через « ; » |
| Report | Авторы, заглавие, город, организация, год, число страниц | Оформляется как книга |
| Patent | Авторы, заглавие, Type, номер, страна, правообладатель, дата публикации | Type пустой → «Патент». Номер и дату заявки допишите в заглавие |
| Statute | Заглавие, Type («Указ Президента РФ»), дата, номер, источник, URL, дата обращения | Выводится как «Заглавие : Указ … от 05.03.2020 № 164 // Источник» |
| Web Page | Заглавие, сайт, URL, дата обращения; автор и год — если есть | Без автора запись ставится по заглавию |

## Ограничения и отличия от строгого ГОСТа

Некоторые требования ГОСТа нельзя выразить средствами CSL — языка, на котором пишутся стили Mendeley. В этих местах стиль следует распространённой практике.

- **Иностранные источники.** Для них используются те же сокращения, что и для русских: «Т.», «С.», «\[и др.\]». Строгий ГОСТ требует сокращений на языке источника: «Vol.», «P.», «\[et al.\]». С метками 0/1 стиль не может переключать язык сокращений: CSL не сравнивает значения полей.
- **Редакторы.** Пишутся в именительном падеже: «редактор С. С. Сидоров», а не «под ред. С. С. Сидорова» — склонять фамилии стиль не умеет.
- **Патенты.** В Mendeley нет полей для номера и даты заявки — их нужно дописывать в заглавие вручную.
- **«\[Электронный ресурс\]».** Этой пометки нет: в ГОСТ Р 7.0.100-2018 она отменена, вместо неё пишется «– URL: … (дата обращения: …)».
- **URL у статей.** Не печатается, даже если заполнен — у статей выводится только DOI. Если статье нужна ссылка, выберите для неё тип Web Page.

Если методичка вуза требует иначе в одном из этих пунктов, стиль можно доработать: сокращения на языке источника, например, включаются заменой меток на «0» и «en».
